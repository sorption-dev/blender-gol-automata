# GOL Automata

Аддон для Blender 3.0+ — генератор «башни-манифеста» на основе клеточного автомата
«Игра Жизнь» Конвея. Каждое поколение автомата — слой башни; ось Z — ось времени,
следующее поколение располагается под предыдущим. Осью времени может служить и
любая кривая сцены — тогда башня растёт по нарисованному пути.

Лендинг и полная документация — **https://sorption.dev/blender-gol-automata**
(исходники сайта живут отдельным репозиторием).

Лицензия — [GPL-3.0-or-later](LICENSE). English readme — [README.md](README.md).

## Правила игры

Игра идёт на клеточном поле — «вселенной»:

- в пустой (мёртвой) клетке, рядом с которой ровно 3 живые, зарождается жизнь;
- живая клетка с 2 или 3 живыми соседями продолжает жить;
- при < 2 или > 3 соседях клетка погибает «от одиночества» или «от перенаселения».

Стартовый рисунок задаёт игрок — это эмбрион системы.

## Установка

Одним файлом, как обычный аддон (Blender 3.0 и новее):
`Edit > Preferences > Add-ons > Install` → выбрать `gol_automata.py` → включить галку.
Панель появится в 3D-вьюпорте: клавиша `N` → вкладка **GOL**.

Начиная с Blender 4.2 аддон собирается и как расширение — в репозитории лежит
`blender_manifest.toml`:

```bash
blender --command extension build --source-dir . --output-dir dist
```

На выходе `dist/gol_automata-1.0.0.zip`: код, манифест, лицензия и README.
Кэш Python и точка-файлы в архив не попадают — за это отвечает
`paths_exclude_pattern` в манифесте. Проверить манифест перед сборкой:
`blender --command extension validate .`

Установить собранный архив можно через `Install from Disk` в настройках или
командой `blender --command extension install-file --repo user_default --enable <zip>`.

## Панель

- **Generate Tower** — запустить автомат и построить башню. **Replace Previous**
  очищает коллекцию `GOL Automata` перед новой генерацией — удобно итерировать.
  Удаляются только объекты, созданные аддоном (метка `gol_generated`): свои
  объекты, положенные в коллекцию, и выбранный Instance Object не пострадают.
  Взрывные правила на больших сетках автоматически останавливаются по бюджету
  (~4 млн вершин), чтобы не заморозить Blender.
- **Seed** — размер вселенной и стартовое состояние:
  - *Random* — случайное заполнение (Density + Seed);
  - *Pattern* — классические паттерны (Glider, R-Pentomino, Acorn, Pulsar,
    Gosper Glider Gun…), штампуются в центр сетки;
  - *Paint* — рисование клеток вручную. Кнопка **Edit Seed** открывает редактор:
    клик по клетке переключает её, есть симметрия X/Y, Clear/Invert/Random,
    и **Step** — прокрутить seed на одно поколение вперёд. Открытие редактора из
    режимов Random/Pattern захватывает текущий seed для доработки руками.
- **Rules** — правила в нотации B/S (Birth/Survive) + пресеты: Conway B3/S23,
  HighLife, Day & Night, Seeds, Maze, Coral… *Wrap Edges* замыкает края в тор.
  *Stop on Repeat* останавливает башню, когда вселенная зациклилась.
  *Noise* на каждом шаге зажигает отдельные клетки по кромке колонии — вселенная
  перестаёт затухать, и башня дорастает до заданной высоты.
  *Noise* — наоборот, не даёт ей затухнуть: на каждом шаге пустая клетка у края
  колонии может сама вспыхнуть, и башня дорастает до заданной высоты. Шум
  трогает только кромку живой области, значение считается хэшем от координат
  и сида — те же настройки всегда дают ту же башню.
- **Tower** — число поколений, размер вокселя, масштаб клетки внутри слота и
  ось времени: *Straight* — вертикаль (вниз или вверх), *Curve* — вдоль кривой
  сцены. В режиме кривой поколения нанизываются на Безье, NURBS или Poly:
  *Fit to Curve* растягивает историю на всю длину пути, *Keep Spacing* держит
  шаг прямой башни, *Align Layers* разворачивает слои поперёк пути, а замкнутый
  сплайн сворачивает время в кольцо.
- **Shape FX** — скульптурные эффекты:
  - *Cell Spacing / Layer Spacing* — отступы между клетками и между поколениями;
  - *Twist* — закрутка башни по спирали;
  - *Taper* — сужение к последнему поколению (шпиль) или расширение;
  - *Age Scale* — клетки-долгожители растут или усыхают;
  - *Jitter* — случайный сдвиг клеток, органичный «руинный» вид.
- **Output** — стиль геометрии: кубы, **воск** (поколения сплавляются в цельную
  гладкую скульптуру: воксельный Remesh + Smooth, неразрушающе — детальность
  крутится слайдером Wax Detail или прямо в модификаторах), плоскости, точки
  (для Geometry Nodes) или инстансы любого объекта. Один меш или объект на поколение. *Weld Cells*
  сваривает соседние клетки и удаляет внутренние грани (чистая оболочка под
  3D-печать). Атрибуты `gol_generation` и `gol_age` пишутся на вершины;
  *Color by Age* вешает материал с градиентом по возрасту клетки.
- **Animation** — рост башни по таймлайну: Build-модификатор (один меш) или
  ключи видимости (объект на поколение).

## Подсказки

- Glider на сетке с *Wrap Edges* рисует бесконечную диагональную нить.
- Diehard на сетке от 30×30 вымирает ровно на 130-м поколении — башня
  с естественным финалом. На меньшем поле рисунок упирается в стенки
  и вместо гибели зацикливается.
- Правило Seeds (B2/S) взрывается — ставьте Cell Scale поменьше.
- Если башня раз за разом обрывается раньше заданной высоты, включите *Noise*
  со значением Amount около 0.01.
- Атрибут `gol_age` доступен в шейдерах через ноду Attribute и в Geometry Nodes
  через Named Attribute.
